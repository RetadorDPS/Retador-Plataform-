# Agentes especializados de RETADOR

Esta carpeta contiene una colección curada de **132 agentes** (asistentes
especializados en formato Markdown con encabezado YAML) listos para usar
dentro de Claude Code en este repositorio. Se activan pidiéndole a Claude
que use uno por su nombre, por ejemplo:

> "Activa el agente UI Designer y ayúdame a mejorar esta pantalla."
> "Usa el Reality Checker para verificar que esta función está lista para producción."

La colección se seleccionó de un paquete público de +280 agentes,
quedándonos solo con lo relevante para una plataforma de marketplace
Cuba/España que además necesita diseño, marketing, soporte y buena
ingeniería (no solo funciones de venta).

## Categorías guardadas

| Carpeta | Cantidad | Para qué sirve en RETADOR |
|---|---|---|
| `design/` | 10 | Diseño de pantallas, identidad visual, experiencia de usuario |
| `marketing/` | 25 | Atraer y fidelizar usuarios (SEO, redes, contenido, crecimiento). Se excluyeron ~11 agentes de plataformas exclusivas del mercado chino (Baidu, Douyin, WeChat, Weibo, etc.) |
| `engineering/` | 17 | Construcción y mantenimiento de la app (frontend, backend, móvil, pagos, i18n, accesibilidad) |
| `product/` | 5 | Priorización de funciones y hoja de ruta del producto |
| `support/` | 6 | Atención al usuario y reportes operativos |
| `testing/` | 9 | Calidad, pruebas, accesibilidad y rendimiento |
| `finance/` | 5 | Contabilidad, análisis financiero, impuestos |
| `sales/` | 9 | Estrategia de ventas y captación de comercios/vendedores |
| `paid-media/` | 7 | Publicidad pagada (Google/Meta Ads, tracking) |
| `security/` | 12 | Seguridad de la aplicación y los datos |
| `project-management/` | 7 | Organización del trabajo y seguimiento de tareas |
| `specialized/` | 11 | Precios, traducción, atención al cliente, estrategia de negocio, orquestación de agentes, entre otros |
| `academic/` | 6 | Investigación de usuarios (psicología, estadística, antropología, etc.) |
| `strategy/` | 3 | Documentos de estrategia y briefs ejecutivos |

## Nota

No se incluyeron categorías sin relación con RETADOR: desarrollo de
videojuegos, GIS/mapas, salud y computación espacial (realidad
virtual/aumentada). Si en el futuro se necesitan, están disponibles en el
paquete de origen (`agency-agents-main`, colección "Agency Agents").
